Put a Whisper speech model (a ggml-*.bin file) in this folder.

Recommended:
  With a graphics card:  ggml-large-v3-turbo.bin (1.6 GB)
      https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo.bin
  Without one:           ggml-small.en.bin (488 MB)
      https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small.en.bin

All models: https://huggingface.co/ggerganov/whisper.cpp/tree/main

WhisperVTT picks up a new model automatically while it is running.
Switch between models under Settings > Model.
